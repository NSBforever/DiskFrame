## DiskFrame 1.4.1

### A redesigned Settings page
- **Two balanced columns** that use the width of the window: how DiskFrame looks and behaves on the left (Appearance, Interface Layout, Window, Playback), what it connects to on the right (Updates, Google Calendar, Search, About & Support). On a narrow window the cards stack into one column, and the last card always stays clear of the dock.
- **Every card follows one pattern**: an icon, a title and a short explanation, with each control lined up on the right.
- **Theme**: one Light / Dark / System control. The current choice is clearly marked, and the arrow keys move between the options.
- **Grid tile size**: a cleaner slider that shows its value as you drag.
- **Updates**: the installed version, the latest version DiskFrame has seen, when it last checked and the update mode, all at a glance, with download progress when an update is on its way.
- **Google Calendar**: the card says plainly whether Calendar is not available in this build, not connected, connected (with the last sync time), expired or failing to sync.
- **About & Support**: version, build, Report an Issue and GitHub in one compact card.

Every setting does what it did before and is saved in the same place: nothing needs to be set again.

### Still the same
- Connecting a Google account is **not switched on yet** in this release; Settings says so clearly. It will be enabled in an update.

### Updating
- **From 1.1.0 or later:** DiskFrame offers this update by itself. Your library, thumbnails, favourites and settings are kept.
- **From 1.0.0 or 1.0.1:** download `diskframe-1.4.1-setup.exe` below and run it once; your library and settings are kept, and later versions arrive automatically.

Windows 10/11, 64-bit. The installer is not code-signed yet, so Windows SmartScreen may show "Windows protected your PC" the first time: choose **More info → Run anyway**. The in-app update verifies the download's checksum either way.
