## DiskFrame 1.6.0

### Update history and What's New
- **See every version and what it changed.** Settings → Updates → **Update History** lists each DiskFrame release, newest first, with its notes, and marks the one you have installed. It reads DiskFrame's public release list from GitHub, as the updater already does, and keeps a copy on this PC so it still opens offline.
- **What's New, once.** After DiskFrame updates itself, the first start shows what the new version brings. It does not come back until the next update, and a fresh install never shows it.

### Help improve DiskFrame, only if you want to
- DiskFrame asks **once** whether it may send anonymous usage counts and short crash summaries. **No thanks** sends nothing; closing the question without answering asks again next time.
- **What is counted:** the DiskFrame and Windows version, that an update was installed, and which features are used (for example "Events opened"). A crash summary says which part of DiskFrame stopped, why, and its exit code (for example "renderer, crashed"). Closing DiskFrame from Task Manager is not counted as a crash.
- **What is never sent:** file names, folders, paths, photos, thumbnails, locations, faces or Calendar details. There is no account and no sign-in.
- Each install is identified only by a random ID created when you agree. **Settings → Privacy** turns usage counts and crash summaries on or off separately, and resets the ID.
- Counts go to PostHog's EU servers. Like any website, they see the connection's internet address; DiskFrame tells them not to use it to look up a location or to build a profile of you.

### Updating
- **From 1.1.0 or later:** DiskFrame offers this update by itself. Your library, thumbnails, favourites, collections and settings are kept; the update only adds new settings.
- **From 1.0.0 or 1.0.1:** download `diskframe-1.6.0-setup.exe` below and run it once; your library and settings are kept, and later versions arrive automatically.

Windows 10/11, 64-bit. The installer is not code-signed yet, so Windows SmartScreen may show "Windows protected your PC" the first time: choose **More info → Run anyway**. The in-app update verifies the download's checksum either way.
